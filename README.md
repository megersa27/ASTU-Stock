# ASTU Stock Management System

A web-based stock management system developed for small and medium-sized businesses.

## Technology Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express.js
- Database: PostgreSQL
- ORM: Prisma
- Containerization: Docker + Docker Compose

## Project Phases

- Phase 0 — Product Planning
- Phase 1 — Software Requirements Specification
- Phase 2 — Software Architecture Design
- Phase 3 — UI/UX Design
- Phase 4 — Environment Setup
